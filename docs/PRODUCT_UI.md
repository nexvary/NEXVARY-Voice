# NEXVARY Voice product experience

Android v0.2 design brief: refined navy/black Material3 Compose with silver outlines, gold accents, vivid electric-teal status indicators and consistent Arabic RTL. Four intentional destinations:

- Home: service connectivity, current supported capabilities, launch shortcuts
- Interpreter: bilingual, alternating microphone/typed turns, Bluetooth output managed by OS, transcript and clear direction swap
- Voice Studio: **live translated speech preview** (NOT virtual microphone injection), SRT subtitle-file translation and export (NOT full dubbing yet)
- Settings: server URL, temporary token, live server health, device/runtime notes

Do not show dead controls pretending to perform automatic dubbing, cloned voices, simultaneous listening, or arbitrary app microphone replacement. Actual voice dubbing and Windows OBS integration remain milestones.
